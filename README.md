# Portfolio

This repository contains my personal portfolio website as a Software Tester and quality assurance.


## Sections

- **Home**: Introduction, role description, and links to projects, CV, and contact details.
- **About**: Profile detail, statistics, and testing philosophy.
- **Education**: Computer & Systems Engineering at Ain Shams University and Software Testing training at DEPI.
- **Skills**: Focus areas including risk-based testing, exploratory testing, and test coverage optimization.
- **Services**: Offerings such as Manual Testing, Automated Testing, API Testing, Database Testing, and Bug Reporting.
- **Projects**: Summary of key work, including a Traffic Light Controller, Vehicle Rental System, and Food Rescue Platform.
- **Contact**: Reach out form with EmailJS integration and direct communication links.

## Technologies Used

- HTML5 for layout and content structure.
- CSS3 for styling, responsive grid systems, and custom mesh gradients.
- JavaScript for vanilla DOM interaction, canvas particle background, interactive easter egg, and form integration.
